# ServerHub

Laboratorio personal de ingeniería, desarrollo e infraestructura.

## Objetivo

ServerHub es un ecosistema destinado al aprendizaje, desarrollo,
despliegue y operación de aplicaciones y servicios.

## Arquitectura

- Servidor: Ubuntu 26.04 LTS
- Contenedores: Docker Engine + Docker Compose
- Desarrollo: VS Code
- Control de versiones: Git / GitHub
- Backend: Python / FastAPI
- Base de datos: PostgreSQL
- Cache: Redis
- Proxy inverso: Nginx
